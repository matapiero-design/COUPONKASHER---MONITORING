# מבנה `netunim.json`

קובץ אחד לשנת מס. נכתב מחדש (במלואו) אחרי כל שלב שאושר, כדי שאפשר יהיה להפסיק באמצע ולחזור בשיחה אחרת.

```json
{
  "shnat_mas": 2025,
  "tik_mas_hachnasa": "123456789",
  "ben_zug_rashum": { "shem": "יעקב כהן", "tz": "012345678", "maamad": "atzmai", "sug_osek": "murshe" },
  "ben_zug": { "shem": "רות כהן", "tz": "087654321", "maamad": "sachir" },
  "yeladim": [ { "shem": "נועה", "taarich_leda": "2014-03-11" } ],

  "shlavim": {
    "0": { "ishur": true,  "taarich": "2026-03-02", "hearot": "" },
    "1": { "ishur": true,  "taarich": "2026-03-02", "hearot": "חסר 106 ממעסיק שני" },
    "2": { "ishur": false, "taarich": null,         "hearot": "ממתין לכרטסת סופית" }
  },

  "sechumim": [
    {
      "shalav": 2,
      "prit": "הכנסה חייבת מעסק",
      "sechum": 184300,
      "kod": "150",
      "kod_meumat": false,
      "amuda": "ben_zug_rashum",
      "makor": "נספח א' טופס 1320, שורת הכנסה חייבת"
    },
    {
      "shalav": 3,
      "prit": "משכורת — מעסיק א'",
      "sechum": 96420,
      "kod": "172",
      "kod_meumat": false,
      "amuda": "ben_zug",
      "makor": "טופס 106 — חברת X, סך תשלומים חייבים"
    }
  ],

  "chaserim": [
    { "mismach": "טופס 106 ממעסיק שני", "mekor": "לבקש ממחלקת שכר", "shalav": 3 }
  ],

  "dgalim": [
    { "shalav": 2, "noseh": "פער של 6,800 ₪ בין המחזור בנספח א' לדוחות המע״מ", "status": "patuach" }
  ]
}
```

## כללים

- **`sechum`** — מספר בלבד, בשקלים שלמים. לא מחרוזת, לא טווח, לא "בערך".
- **`makor`** — חובה ולא ריק. סכום בלי מקור לא נכנס לקובץ ולא נכנס לגיליון.
- **`kod`** — מספר השדה בטופס. אם לא ידוע או לא אומת מול הטופס לשנת המס: השאר `null` ורשום `kod_meumat: false`. הסקריפט יסמן אותו בגיליון כ"לאמת" במקום להציג מספר שאולי שגוי.
- **`kod_meumat`** — `true` רק אחרי שהמשתמש אישר את הקוד מול המסך או מול הטופס הרשמי.
- **`amuda`** — `"ben_zug_rashum"` או `"ben_zug"`. קובע לאיזו עמודה בטופס הסכום שייך.
- **`shlavim`** — `ishur: true` נרשם **רק** אחרי אמירה מפורשת של המשתמש. לא להסיק אישור משתיקה או מהמשך השיחה.
- **`dgalim`** — דברים שהוצפו ולא נסגרו. `status` הוא `"patuach"` או `"nisgar"`. דגל פתוח מוצג שוב בשלב 8.
